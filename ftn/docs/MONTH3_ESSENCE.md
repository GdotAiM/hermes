`next_setup` is an **annotation**, not a ticket.

M3 is the institutional-context and next-setup anticipation layer.
It accumulates labeled timeframe, IOF, sponsorship, institutional-structure
and macro→micro context, then records an anticipated next setup as an
annotation. M3 may publish reusable institutional context. It does not
replace M9 `pair_institutional`, create a competing vote, select an M9
candidate, create a ticket, or route an order.

Process is **context accumulation → anticipation**, not
A AND B AND C AND D → opportunity.
